## Scryfall-derived card data

Three committed JSON files map the names the XMage engine uses to Scryfall card identifiers, so the browser can build `cards.scryfall.io` image URLs without calling the rate-limited API during play:

- `web/src/data/scryfall-cards.generated.json` — card name (and an NFD-folded alias of each name) to Scryfall card UUID, plus a `backs` list for front-face names whose back face carries its own image.
- `web/src/data/scryfall-printings.generated.json` — set/number keys to `[UUID, name]`.
- `web/src/data/scryfall-token-arts.generated.json` — token name to the list of `{id, set, num, released}` records for every distinct token artwork.

They are generated by `scripts/build-scryfall-image-index.mjs`, which streams Scryfall's `oracle-cards`, `default-cards`, and `unique-artwork` bulk files. The committed files contain identifiers, names, set codes, and collector numbers only; they contain no card images, rules text, or mana costs.

Source: Scryfall, <https://scryfall.com>. Scryfall publishes card data and images under the Wizards of the Coast Fan Content Policy and its API guidelines (<https://scryfall.com/docs/api>): the data is free for Magic software and community content, may not be paywalled, may not be repackaged or proxied as a substitute for Scryfall, and must not imply Scryfall endorsement. The runtime client fetches card images from `cards.scryfall.io` and does not call the rate-limited API to resolve them.

## Card images committed for the demo and gallery

`web/public/showcase/` contains 13 JPEG art crops, from `web/public/showcase/island.jpg` through `web/public/showcase/giant-growth.jpg`. They are downloaded by `scripts/gen-showcase-art.mjs` through `https://api.scryfall.com/cards/named`, using the `image_uris.art_crop` field. The images are Magic card artwork copyright Wizards of the Coast and are not licensed under MIT. The generator writes only a card-name-to-path map in `web/src/data/showcaseArt.generated.json`; artist and copyright metadata are not stored in that manifest.

All other card images are fetched at runtime from Scryfall's image CDN and are not part of this repository.

## Google Fonts

`web/index.html` loads four families from Google's Fonts CDN at runtime: Cinzel, Merriweather, Noto Sans JP, and Noto Sans SC. No font binaries are committed to this repository. The offline metadata table records all four families as `OFL`.

`.opencode/skills/ui-ux-pro-max/data/google-font-licenses.json` is a 1,934-family snapshot derived from Google's google/fonts repository (`METADATA.pb`, revision `038b637da7b3fd956a4ed93ffc607c3d5e4ce172`). It records Google's license codes: 1,894 `OFL`, 35 `APACHE2`, and 5 `UFL`. Eight families with no exact `METADATA.pb` entry are listed in `excludedFamilies` with the reason recorded, and carry no license code in this snapshot. The companion `google-fonts.csv` holds the catalog fields for the same 1,934 families. Neither file ships in the web build; both are data for the vendored design skill. License texts and font files live in the upstream google/fonts repository, not here.

## `site/` dashboard and demo material

`site/` is a static, zero-build dashboard. `site/content.json` is the canonical copy; `site/status.json` is generated by `scripts/gen-dashboard.mjs` from `site/content.json` plus test artifacts; `site/index.html`, `site/status.html`, `site/app.js`, and `site/styles.css` are first-party.

Artwork:

- `site/assets/logo.jpg` and `site/assets/og-cover.jpg` are original XMage Nexus branding and contain no Wizards of the Coast artwork or marks. `site/assets/favicon.svg` is a simple gold "M" monogram on a dark circle.
- `site/assets/card-back.svg` is a generic card back drawn with gradients for the site; it is not a reproduction of a Magic card back.
- `site/assets/demo/login-and-create-table.webp`, `site/assets/demo/cast-spell.webp`, and `site/assets/demo/combat.webp` are animated screen recordings of this web client. The card faces visible in the recordings are Scryfall-served Wizards of the Coast card images; the recordings themselves are project material.

## Recorded and synthetic fixtures

`web/fixtures/recorded/` holds 125 JSON fixture files plus a `manifest.json` index, recorded from an XMage server by `scripts/record.mjs`, with drivers listed in `scripts/drivers/manifest.mjs`. Most files store a `recordedAt` timestamp, a `gameId`, and a validated `gameView` containing players, permanents, stack objects, and card names and set codes; four files deviate — `learn-raw-target.json` is a raw proxy frame, `sealed-pool.json` and `tournament-end.json` store tournament payloads, and `top-card-peek-sequence.json` stores a three-view `views` sequence. They are not derived from Scryfall and contain no card images or Scryfall identifiers. The other files in `web/fixtures/` (for example `web/fixtures/fake.ts` and `web/fixtures/fakeCore.ts`) are synthetic test doubles written for this project.

## Deck data
